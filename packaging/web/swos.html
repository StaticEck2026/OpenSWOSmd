You need your own copy of the game

OpenSWOS does not include Sensible World of Soccer's graphics, sound or team data. OpenSWOS Setup makes them, once, from a copy you own:

  • PC version (recommended): buy it on GOG and point the setup at the installed game folder.
  • Amiga version: point the setup at the two disk images (.adf) of your SWOS 96/97 disks. With both versions you also get the Amiga graphics, music and loading screens.
  • Atari Jaguar (optional): the Sensible Soccer International Edition cartridge image adds the Jaguar sprites.

Windows: run the installer; OpenSWOS Setup starts when it finishes. macOS: open OpenSWOS Setup from the zip. Linux: run swosdata from the portable zip. Amiga: the zip is a SWOS drawer; fill it with Amiga version → Add the game data in OpenSWOS Setup, then copy it to your Amiga.

Where your files are

SWOS.ini (settings) and SWOS.log sit in the folder below. Your saved games are in save inside it, and are left alone when you reinstall.

PlatformFolder
Windows%USERPROFILE%\Documents\SWOS
macOS~/Library/Application Support/SWOS
Linux~/.swos
Amigasave/ beside the game
Switchsave:/
Web/save (in the browser's storage)

Reporting a bug

Say which build you are on — it is on the bottom line of the main menu and in the window title, and it is the first line of SWOS.log. Attach that log if the game crashed.
